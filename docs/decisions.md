# Architecture Decision Records (ADR)

Record each significant technical or scope decision here so the team (and AI agents) can see what was decided and why. Fill this file in place: keep the template below and add real decisions underneath it, newest at the bottom. Never delete old records. If a decision changes, mark the old one **Superseded** and add a new record.

**Status values:** Proposed · Accepted · Superseded by ADR-XXX · Rejected

---

## ADR Template

> **This is a template, not a team decision.** Copy the block below into the Decisions Log for each new decision and replace the placeholders.

### ADR-XXX: <Short title>

- **Date:** YYYY-MM-DD
- **Status:** Proposed
- **Decided by:** <names>

**Decision**
What we decided, in one or two sentences.

**Context**
The problem or situation that required a decision, and the constraints (time, skills, tools).

**Alternatives Considered**
1. Option A — pros / cons
2. Option B — pros / cons

**Rationale**
Why this option was chosen over the others.

**Consequences**
What becomes easier, what becomes harder, and what follow-up work or risks this creates.
